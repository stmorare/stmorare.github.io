# 1. Project Vision

PortfolioPro is a premium recruiter-focused personal portfolio website that showcases the professional profile of Simphiwe Tebogo Morare.

The website must communicate professionalism, technical competence, attention to detail and modern engineering practices.

This project is intentionally being developed as if it were a commercial software engineering project instead of a simple personal website.

The project itself should become part of the portfolio.

---

# 2. Primary Goals

The portfolio should help achieve the following objectives:

• Showcase enterprise IT experience

• Demonstrate software engineering principles

• Showcase technical projects

• Demonstrate Git proficiency

• Demonstrate professional documentation

• Demonstrate clean architecture

• Demonstrate modern frontend development

• Showcase certifications

---

# 3. Long-Term Vision

This repository should eventually evolve into a reusable portfolio template that can be customized and sold to future clients.

The architecture should therefore favour maintainability, scalability and reusability.

# 5. Learning Philosophy

The owner is NOT attempting to become a full-time software developer.

The goal is to understand how professional software projects are built and to become highly capable at reading, understanding and maintaining code.

Every engineering decision should therefore be explained before implementation.

Assume beginner-level software engineering experience.

Never assume prior knowledge.

Explain concepts before commands.

# 13. Coding Standards

Prefer readability over clever code.

Use meaningful naming.

Use comments sparingly.

Keep functions small.

Keep components reusable.

Avoid duplication.

Follow TypeScript best practices.

---

# 14. Commit Philosophy

Commits should represent logical milestones.

Avoid commits like:

"Update"

"Fix"

"Changes"

Prefer messages such as:

docs: add project documentation

feat: build hero section

style: improve responsive layout

refactor: simplify navigation component
