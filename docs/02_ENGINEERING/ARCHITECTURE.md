# Architecture

## Why Next.js?

Next.js provides the project structure, routing, image optimization, and production tooling needed to build a modern portfolio website while following professional software engineering practices.

---

## Why React?

React allows the website to be built using reusable components, making the project easier to maintain, scale, and reuse in future client projects.

---

## Why TypeScript?

TypeScript improves code quality by detecting mistakes early and making the code easier to understand and maintain.

---

## Why Tailwind CSS?

Tailwind CSS enables rapid development of a clean, responsive, and consistent user interface without writing large custom CSS files.

---

## Why GitHub Pages?

GitHub Pages provides free, reliable hosting and integrates naturally with the project's GitHub repository.

---

## Why a Single Git Repository?

Maintaining one repository keeps version control simple, avoids nested Git repositories, and reflects professional software engineering practices.

---

## Why Documentation First?

Documentation captures engineering decisions, supports learning, and allows another developer or AI assistant to continue the project with minimal onboarding.

---

## Overall Architecture

PortfolioPro follows a documentation-first workflow, uses Git for version control, Next.js as the frontend framework, and GitHub Pages for deployment.
